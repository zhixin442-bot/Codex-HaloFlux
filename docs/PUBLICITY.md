## English project introduction

> Codex-HaloFlux is a silent Windows wallpaper that lights up in response to local Codex tool and task events. It preserves the original HALOFLUX ring, particles and layered beams. Windows 11 and Lively WebView2 have been tested. The project is an independent, noncommercial community adaptation.  
> Original work: HALOFLUX by Ryder191 (RYDER CODE / Ms MAIKEBAIs CAT)
