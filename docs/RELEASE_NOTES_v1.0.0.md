# Codex-HaloFlux v1.0.0

Draft for release review.

Codex-HaloFlux is a noncommercial Windows live wallpaper modified from **HALOFLUX by Ryder191 (RYDER CODE / Ms MAIKEBAIs CAT)**. The community project is independent of OpenAI. [Original HALOFLUX](https://github.com/Ryder191/haloflux) · [License](../LICENSE) · [Attribution](../NOTICE)

## Highlights

- Original Canvas halo, particles, light beams, data panels and camera motion.
- Silent ambient mode and optional real Codex activity across local projects.
- Local-only bridge with multi-session state and a 30-second tool activity window.
- Opt-in, reversible user-scope installation with configuration backups.
- Setup and tuning documentation in the project, with English and Simplified Chinese entry points.

## Download and setup

The planned Windows asset is `Codex-HaloFlux-v1.0.0-windows.zip` with a separate SHA-256 checksum. Use the official Node.js Windows distribution, PowerShell 7.4 or newer for event-mode setup, and Lively WebView2 for desktop display. [Installation](INSTALL.md) · [Uninstall](UNINSTALL.md) · [FAQ](FAQ.md)

## Compatibility

Windows 11 passed isolated installation and rollback, native Codex tool events and Lively WebView2 desktop rendering. Native Codex ran a read-only local MCP test tool with a local fixture model response. Some Lively switch-away and exit scenarios have partial coverage. Windows 10 remains unverified.
