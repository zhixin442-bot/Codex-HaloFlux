# Roadmap candidates

These are directions for community proposals. v1.0.0 ships the Windows implementation described in the [acceptance report](FINAL_ACCEPTANCE.md).

- Verify Windows 10 with a real installation and expand the Lively lifecycle test matrix.
- Add more verifiable Codex events, improve multi-session presentation and explore richer halo feedback.
- Profile 4K rendering, then evaluate frame pacing, resource limits and automatic pause using measurements. [Performance guide](PERFORMANCE_TUNING.md)
- Explore importable community presets with clear asset and redistribution rights.
- Evaluate adapters for other local AI agents with explicit opt-in and the same data minimization.

Open an issue with a reproducible baseline or a focused proposal before expanding the public event contract. [Contributing](../CONTRIBUTING.md)
