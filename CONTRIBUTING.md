# Contributing

Issues, bug reports and pull requests are welcome. For a bug report, include Windows and app versions, ambient or live mode, expected behavior, and a minimal reproduction. Use a test fixture and remove names, local paths, identifiers, credentials, prompt text and tool output. Report security issues using [SECURITY.md](SECURITY.md).

Keep renderer changes focused and keep the source attribution intact. Describe the origin and license of any proposed code or asset, including screenshots and music. The upstream noncommercial terms and platform attribution conditions apply when modifying or redistributing this project. The visibility of a repository gives no permission to use HALOFLUX commercially. [LICENSE](LICENSE) · [NOTICE](NOTICE)

See [development setup](docs/DEVELOPMENT.md), [architecture](docs/ARCHITECTURE.md), [performance tuning](docs/PERFORMANCE_TUNING.md) and [test evidence](docs/FINAL_ACCEPTANCE.md). Use the isolated test for Hook changes and include the outcome in your pull request.
